# Highlights App (هایلایتس)

کافیست هر لینکی را در برنامه ذخیره کنید؛ هایلایتس سلامت لینک (زنده یا مرده بودن) را بررسی کرده، پیش‌نمایش کاملی از صفحه (عنوان، توضیحات و تصویر) استخراج می‌کند و آن را با امکاناتی مثل برچسب‌گذاری چندگانه، جستجوی همزمان و بررسی خودکار روزانه روی قفسه شخصی شما نگه می‌دارد.

---

## امکانات اصلی

- **بررسی خودکار سلامت لینک‌ها (Health Check):** ارسال درخواست از سرور به لینک‌های ثبت‌شده برای تشخیص سالم بودن (`ok`) یا از کار افتادن (`dead`).
- **استخراج پیش‌نمایش (Open Graph Scraping):** دریافت عنوان، توضیحات، نام سایت و تصویر شاخص از متاتگ‌های Open Graph به همراه راهکارهای جایگزین برای صفحات بدون متاتگ.
- **برچسب‌گذاری و فیلتر:** پشتیبانی از تگ‌های چندگانه برای هر لینک فیلتر سریع بر اساس وضعیت لینک و شمارش لحظه‌ای تعداد لینک‌ها.
- **جستجوی متنی لحظه‌ای:** جستجوی هوشمند در عناوین، آدرس‌ها، توضیحات و تگ‌ها.
- **بررسی روزانه خودکار (Background Cron Job):** فرایند پس‌زمینه خودکار برای بررسی مجدد سلامت همه لینک‌ها و به‌روزرسانی پیش‌نمایش آن‌ها.
- **صفحه‌بندی کارآمد (Pagination):** نمایش مرتب با شمارش دقیق تعداد کل صفحات و صفحات بعدی/قبلی.
