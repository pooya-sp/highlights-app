# Highlights App (هایلایتس)

یک وب‌اپلیکیشن فول‌استک «بعداً می‌خوانم» (Read-it-later). کافیست هر لینکی را در برنامه ذخیره کنید؛ هایلایتس سلامت لینک (زنده یا مرده بودن) را بررسی کرده، پیش‌نمایش کاملی از صفحه (عنوان، توضیحات و تصویر) استخراج می‌کند و آن را با امکاناتی مثل برچسب‌گذاری چندگانه، جستجوی همزمان و بررسی خودکار روزانه روی قفسه شخصی شما نگه می‌دارد.

---

## امکانات اصلی

- **بررسی خودکار سلامت لینک‌ها (Health Check):** ارسال درخواست از سرور به لینک‌های ثبت‌شده با محدودیت ۵ ثانیه برای تشخیص سالم بودن (`ok`) یا از کار افتادن (`dead`).
- **استخراج پیش‌نمایش (Open Graph Scraping):** دریافت عنوان، توضیحات، نام سایت و تصویر شاخص از متاتگ‌های Open Graph به همراه راهکارهای جایگزین برای صفحات بدون متاتگ.
- **امنیت در برابر حملات SSRF:** اعتبارسنجی دقیق URL قبل از ارسال هرگونه درخواست به وب جهت مسدودسازی آدرس‌های داخلی، شبکه محلی (Private IPs)، لوکال‌هاست و سرویس‌های متادیتای ابری.
- **احراز هویت کامل با JWT:** ثبت‌نام و ورود امن با هش کردن گذرواژه‌ها توسط bcrypt و نگهداری توکن‌ها در کوکی‌های امن `httpOnly` (محافظت کامل در برابر حملات XSS).
- **برچسب‌گذاری و فیلتر:** پشتیبانی از تگ‌های چندگانه برای هر لینک با استفاده از ایندکس Multikey مونگو، فیلتر سریع بر اساس وضعیت لینک و شمارش لحظه‌ای تعداد لینک‌ها.
- **جستجوی متنی لحظه‌ای:** جستجوی هوشمند (با تاخیر ۳۰۰ میلی‌ثانیه برای تایپ بدون افت سرعت) در عناوین، آدرس‌ها، توضیحات و تگ‌ها.
- **بررسی روزانه خودکار (Background Cron Job):** فرایند پس‌زمینه خودکار در ساعت ۳ بامداد برای بررسی مجدد سلامت همه لینک‌ها و به‌روزرسانی پیش‌نمایش آن‌ها.
- **صفحه‌بندی کارآمد (Pagination):** نمایش مرتب با شمارش دقیق تعداد کل صفحات و صفحات بعدی/قبلی.

## معماری پروژه

پروژه به صورت یک مخزن یکپارچه (Monorepo) سازمان‌دهی شده است:

```
highlights_app/
├── client/              # بخش فرانت‌اند با Next.js 16
│   ├── src/app/         # صفحات، کامپوننت‌های سرور و Server Actions
│   ├── src/components/  # کامپوننت‌های رابط کاربری و تعاملی
│   └── src/lib/         # کلاینت ارتباط با API و تایپ‌ها
│
└── server/              # بخش بک‌اند با Express 5 و Mongoose
    ├── src/routes/      # مسیرهای API (محافظت‌شده با میدل‌ور احراز هویت)
    ├── src/controllers/ # پردازش درخواست‌ها و پاسخ‌ها
    ├── src/services/    # منطق اصلی (بررسی لینک، استخراج متاتگ و ساخت حساب)
    ├── src/models/      # اسکیماهای Mongoose
    ├── src/jobs/        # فرایندهای زمان‌بندی‌شده (Cron Jobs)
    └── src/utils/       # ابزارهای کمکی (اعتبارسنجی SSRF، خطاها و تگ‌ها)
```

تمام درخواست‌ها به سرور بک‌اند از طریق سرور نکسوس (Server Components و Server Actions) ارسال می‌شوند و کلاینت دسترسی مستقیمی به توکن JWT ندارد.

## راهنمای راه‌اندازی محلی

### پیش‌نیازها
- Node.js نسخه ۲۰ یا بالاتر
- بسته pnpm
- حساب کاربری MongoDB Atlas یا مانگو محلی

### ۱. راه‌اندازی سرور (بک‌اند)

```bash
cd server
pnpm install
cp .env.example .env     # مقادیر DATABASE_URL و JWT_SECRET را تنظیم کنید
pnpm dev                 # اجرا روی پورت 20000
```

### ۲. راه‌اندازی فرانت‌اند

```bash
cd client
pnpm install
pnpm dev                 # اجرا روی پورت 3000
```

سپس در مرورگر خود آدرس `http://localhost:3000` را باز کنید.

### ۳. اجرای تست‌ها

```bash
cd server
pnpm test                # اجرای تست‌های یکپارچگی و توابع
```

## فهرست مسیرهای API

| متد | مسیر | توضیحات | احراز هویت |
|---|---|---|---|
| POST | `/api/v1/auth/register` | ثبت‌نام و ورود خودکار | عمومی |
| POST | `/api/v1/auth/login` | ورود به حساب کاربری | عمومی |
| GET | `/api/v1/auth/me` | دریافت مشخصات کاربر فعلی | نیازمند توکن |
| POST | `/api/v1/links` | ذخیره لینک جدید به همراه بررسی سلامت و تگ‌ها | نیازمند توکن |
| GET | `/api/v1/links` | دریافت لیست لینک‌ها (با پشتیبانی از page, limit, status, tag, search) | نیازمند توکن |
| GET | `/api/v1/links/:id` | دریافت اطلاعات یک لینک خاص | نیازمند توکن |
| DELETE | `/api/v1/links/:id` | حذف لینک | نیازمند توکن |
| POST | `/api/v1/links/:id/recheck` | بررسی دستی مجدد یک لینک | نیازمند توکن |
| PATCH | `/api/v1/links/:id/tags` | ویرایش تگ‌های لینک | نیازمند توکن |
