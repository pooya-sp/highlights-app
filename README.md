# Highlights App (هایلایتس)

یک وب‌اپلیکیشن فول‌استک (Read-it-later). کافیست هر لینکی را در برنامه ذخیره کنید؛ هایلایتس سلامت لینک (زنده یا مرده بودن) را بررسی کرده، پیش‌نمایش کاملی از صفحه (عنوان، توضیحات و تصویر) استخراج می‌کند و آن را با امکاناتی مثل برچسب‌گذاری چندگانه، جستجوی همزمان و بررسی خودکار روزانه روی قفسه شخصی شما نگه می‌دارد.

---

## امکانات اصلی

- **بررسی خودکار سلامت لینک‌ها (Health Check):** ارسال درخواست از سرور به لینک‌های ثبت‌شده با محدودیت ۵ ثانیه برای تشخیص سالم بودن (`ok`) یا از کار افتادن (`dead`).
- **استخراج پیش‌نمایش (Open Graph Scraping):** دریافت عنوان، توضیحات، نام سایت و تصویر شاخص از متاتگ‌های Open Graph به همراه راهکارهای جایگزین برای صفحات بدون متاتگ.
- **برچسب‌گذاری و فیلتر:** پشتیبانی از تگ‌های چندگانه برای هر لینک با استفاده از ایندکس Multikey مونگو، فیلتر سریع بر اساس وضعیت لینک و شمارش لحظه‌ای تعداد لینک‌ها.
- **جستجوی متنی لحظه‌ای:** جستجوی هوشمند (با تاخیر ۳۰۰ میلی‌ثانیه برای تایپ بدون افت سرعت) در عناوین، آدرس‌ها، توضیحات و تگ‌ها.
- **بررسی روزانه خودکار (Background Cron Job):** فرایند پس‌زمینه خودکار در ساعت ۳ بامداد برای بررسی مجدد سلامت همه لینک‌ها و به‌روزرسانی پیش‌نمایش آن‌ها.
- **صفحه‌بندی کارآمد (Pagination):** نمایش مرتب با شمارش دقیق تعداد کل صفحات و صفحات بعدی/قبلی.

## معماری پروژه

پروژه به صورت یک مخزن یکپارچه (Monorepo) سازمان‌دهی شده است:

```
highlights_app/
├── client/              # بخش فرانت‌اند با Next.js 16
│   ├── src/app/         # صفحات، کامپوننت‌های سرور و Server Actions
│   ├── src/components/  # کامپوننت‌های رابط کاربری و تعاملی
│   └── src/lib/         # کلاینت ارتباط با API و تایپ‌ها
│
└── server/              # بخش بک‌اند با Express 5 و Mongoose
    ├── src/routes/      # مسیرهای API (محافظت‌شده با میدل‌ور احراز هویت)
    ├── src/controllers/ # پردازش درخواست‌ها و پاسخ‌ها
    ├── src/services/    # منطق اصلی (بررسی لینک، استخراج متاتگ و ساخت حساب)
    ├── src/models/      # اسکیماهای Mongoose
    ├── src/jobs/        # فرایندهای زمان‌بندی‌شده (Cron Jobs)
    └── src/utils/       # ابزارهای کمکی (اعتبارسنجی SSRF، خطاها و تگ‌ها)
```

تمام درخواست‌ها به سرور بک‌اند از طریق سرور نکسوس (Server Components و Server Actions) ارسال می‌شوند و کلاینت دسترسی مستقیمی به توکن JWT ندارد.
